# 07 — SEO & Discoverability

## Critical SEO Principle

**A public content page MUST remain discoverable** by search engines and AI/agentic systems.

**Do NOT**:

- Convert SEO-critical content to unnecessary client-only rendering
- Remove SSR from public editorial routes
- Hide content behind authentication without reason
- Break canonical URLs or internal links
- Remove structured data

## SSR Routes (CURRENT)

**TanStack Start** with **Nitro** for Vercel

Located in: `src/routes/` (not `src/pages/`)

### SEO-Critical Routes

1. **`/briefings/:slug`** (`briefings.$slug.tsx`)
   - Daily Skinny articles
   - Server-renders full content + metadata
   - Article JSON-LD

2. **`/reviews/:slug`** (`reviews.$slug.tsx`)
   - Product reviews
   - Server-renders verdict, ingredients, metadata
   - Product + Review JSON-LD
   - Community rating if available

3. **`/ingredients/:slug`** (`ingredients.$slug.tsx`)
   - Ingredient profiles
   - Server-renders description, function, sources
   - No specific JSON-LD (informational)

4. **`/spotlight/:slug`** (`spotlight.$slug.tsx`)
   - Brand profiles
   - Server-renders brand info

5. **`/sitemap.xml`** (`sitemap[.]xml.ts`)
   - Live-generated from database
   - Queries latest content
   - Never stale

6. **`/web-stories/:slug`** (`web-stories.$slug.ts`)
   - AMP Story format
   - SEO-indexed (except promotional)

### SSR Pattern

```typescript
// src/routes/example.$slug.tsx
import { createFileRoute } from '@tanstack/react-router';
import { createServerFn } from '@tanstack/react-start';

// Server function (runs on server)
const fetchData = createServerFn('GET', async (slug: string) => {
  const supabase = createSupabaseServerClient();
  const { data } = await supabase
    .from('table')
    .select()
    .eq('slug', slug)
    .single();
  return data;
});

// Route definition
export const Route = createFileRoute('/example/$slug')({
  loader: ({ params }) => fetchData(params.slug),
  component: ExamplePage
});

function ExamplePage() {
  const data = Route.useLoaderData();
  return <div>{/* Render content */}</div>;
}
```

## Structured Data (JSON-LD)

### Product Reviews

```typescript
import { enhancedProductReviewJsonLd } from "@/lib/seo/jsonLd";

const jsonLd = enhancedProductReviewJsonLd({
  review: {
    title, brand, verdict, score,
    seo_title, seo_description,
    key_ingredients_structured,
    community_rating,
    community_rating_count
  }
});

<script type="application/ld+json">
  {JSON.stringify(jsonLd)}
</script>
```

**Rules**:

- ONE Product node per page
- ONE editorial review (0-10 score)
- AT MOST ONE aggregateRating (1-5, real reviews only)
- Never fabricate ratings

## Sitemap

**Live SSR** (`/sitemap.xml`):

Queries:

- `news_articles_public` (briefings)
- `ai_generated_product_reviews` (product reviews)
- `marketplace_products` (OpenHaus)
- `marketplace_brands` (brands)
- `ingredients` (profiles)
- Static routes (`src/lib/sitemap/staticRoutes.ts`)

**Fallback** (`public/sitemap.xml`):

- Generated at build time
- Used if SSR unavailable
- Generated by `scripts/generate-sitemap.ts`

**Core Web Vitals**:

- LCP < 2.5s
- FID < 100ms
- CLS < 0.1

**SSR benefits**:

- Faster First Contentful Paint
- Content visible to crawlers immediately
- Better perceived performance
